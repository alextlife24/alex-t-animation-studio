# Alex T Animation Studio

Alex T 的動畫系列作品庫。每個系列一個資料夾，底下每集一個資料夾，各自包含可重現製作的程式碼、劇本、字幕與操作說明。成片 MP4 不放進 Git 歷史，而是附在各集的 GitHub Release。

```
series/
  <系列>/
    <集數>/
```

## 系列與集數

### 本能服務｜Instinct Service

直式低多邊形 3D 黑色幽默系列：動物的真實生物特性，撞上人類的社交禮儀與服務業規範。
